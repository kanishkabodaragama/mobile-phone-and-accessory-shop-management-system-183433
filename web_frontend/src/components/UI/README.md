# UI Components

Ocean Professional base UI primitives used across the app.

- Button: primary, secondary, ghost variants
- Card: content container
- Modal: simple overlay dialog
- Table: basic table for data-heavy pages
- Input, Select: form controls
- Badge: status indicators (success, error, info)
- Tabs: simple tabs
- Spinner: loading indicator
- DateRangePicker: placeholder using two date inputs

These components use CSS classes and theme tokens defined in index.css and App.css.
